# OpenTranslate

OpenTranslate is an open-source AI-powered document translation platform designed to translate large documents, datasets, and knowledge repositories into English.

## Mission

Make high-quality document translation accessible, transparent, and self-hostable.

## Current Status

🚧 In Development

### MVP Goal

Upload PDF → Translate to English → Download translated document.

## Planned Features

- PDF Translation
- DOCX Translation
- Excel Translation
- OCR Support
- OpenAI Integration
- Ollama Integration
- Translation Memory
- Batch Processing
